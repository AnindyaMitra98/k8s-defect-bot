{{- if .Values.nodeAgent.enabled }}

Node agents report every {{ .Values.nodeAgent.intervalSeconds }}s. Give them one
interval, then check they are all in:

  kubectl -n {{ .Release.Namespace }} get daemonset {{ include "k8s-defect-bot.agentName" . }}
  kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/component=node-agent --tail=20

A node missing from /api/nodes usually has a taint the DaemonSet doesn't tolerate.
{{- if not .Values.nodeAgent.privileged }}

The node_kernel_errors check (OOM kills, blocked tasks, I/O errors from the kernel
ring buffer) is off. Enable with --set nodeAgent.privileged=true and add
node_kernel_errors to nodeAgent.enabledChecks -- it runs the agent as root.
{{- end }}
{{- end }}

  curl -X POST localhost:8080/api/notifications/test -H "Authorization: Bearer <api-token>"

something actually changes.
